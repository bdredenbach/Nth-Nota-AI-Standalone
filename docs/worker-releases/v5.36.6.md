# Shared AI Worker v5.36.6 · Testing allowance

Verified November 22, 2026 for Nth Nota AI Standalone and the launchers that use the shared text service.

During testing, cloud chat and writing can use the remaining free allowance from the providers. A provider can still return a rate limit when its free allowance runs out. The change is active on the shared service and works with the existing Android app.
